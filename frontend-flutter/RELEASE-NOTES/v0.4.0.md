## Breakdown 0.4.0

First **stable** release of the Breakdown Android app's 0.4.0 line — the
graduation of the `0.4.0-alpha.1` → `0.4.0-beta.62` series. Full changelog:
[`frontend-flutter/CHANGELOG.md`](https://github.com/tradem/breakdown-rs/blob/v0.4.0/frontend-flutter/CHANGELOG.md).

### Highlights

- **Wardrobe split into `Piece` and `Outfit` (#739):** a fundus garment and a character's composed look are separate surfaces now — the look carries layering and `variant_of` forks, scenes cast outfits (never bare pieces), and the presentation tree moved to `features/pieces/`
- **Scene detail redesign (#834), with the cast (#902) and the shooting days (#903) as real tables:** numeral + location identity block, planning before casting, row menus and a date row action instead of five squeezed icon buttons
- **AI script import, end-to-end:** a block-less import takes its target block from the script (#827–#829), a resumed run continues at the first incomplete chunk (#871), staged per-row apply progress + honest coarse ETAs, a cost card that leads with money and model, and a jobs list that identifies each row
- **Apply is robust:** it survives the app going away (`202` + the run's own stream), a crashed run no longer wedges the client for ten minutes (#805), a re-apply asks first (#800), and an apply that cannot run says why instead of doing nothing
- **Permissions say themselves up front (#809, #816):** Settings → KI is always visible, reads the deployment predicate from `GET /v1/me/capabilities` and renders "Keine Berechtigung" without dispatching — an unknown answer is never a denial
- **Honest errors:** a rejected save names the reason and the fix (all sixteen `ai-config.*` wire codes are explained), a degraded AI provider says so once instead of three times (#822), and Dispo/Soll-Ist rows render `Szene {n}` / `Tag {day} · {location}` instead of a model dump (#766)
- **Planning surfaces:** mood lines reinforced with Material icons (#721), `<Episode>.<Scene>` schedule rows, and per-day-group shooting-day decisions in the apply card (#706) behind the EU AI Act review gate
- **Shell and fundus:** sticky top-bar redesign (#638), cross-season costume fundus browse with a project-scoped Drift cache (#625), and the Deja-vu Cat beyond the splash (#640)
- **Under the hood:** the `Series` → `Project` rename reached the wire, the DAOs and every call site (#591, #599, Drift v13), and two reconciliation fixes — a command that adds no optimistic row now waits for the projection (#916), and an inline edit no longer flashes the old value back (#917)

### Install the APK for YOUR device architecture

(most modern devices: **arm64-v8a**)

- `breakdown-0.4.0-arm64-v8a.apk` — arm64-v8a (modern phones/tablets)
- `breakdown-0.4.0-armeabi-v7a.apk` — armeabi-v7a (older devices)
- `breakdown-0.4.0-x86_64.apk` — x86_64 (emulators, x86 devices)
- `breakdown-0.4.0.aab` — Play-Store bundle (for the future Play channel)

Sideloading: enable "Install unknown apps" for your file manager/browser,
then install the downloaded APK directly — no store account required.
A later install with the same project key updates in place (no uninstall
needed). Updating from any `0.3.0` or `0.4.0-alpha.*`/`-beta.*` build works
the same way.

Version: `0.4.0+155` (`pubspec.yaml` is the single version source; tags are
`v<build-name>`).
